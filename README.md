
# Sales Analytics Dashboard

## Project Overview
This project analyzes sales data using SQL and Power BI to understand sales performance, profit, product categories, city-wise sales, and monthly sales trends.

## Tools & Technologies
- **MySQL** — Data storage and SQL queries
- **Microsoft Power BI** — Dashboard and data visualization
- **DAX** — Calculating profit margin

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales by Category
- Sales by City
- Monthly Sales Trend
- Interactive Category and City Filters

## Key Insights
- Electronics is the highest-selling product category.
- Bhopal has the highest sales among the cities shown.
- April shows a sales peak in the monthly trend.
- The dashboard helps compare sales and profit performance.

## Dataset
The project uses sample sales data created for learning and demonstration purposes.

## Project Goal
To practice SQL, data analysis, DAX calculations, and interactive dashboard development.
